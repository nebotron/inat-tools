## Cursor Cloud specific instructions

- Commit and push any code changes at the end of every prompt.
- Push changes directly to `main`.
- When work lives on a feature branch, merge it into `main` (fast-forward or merge commit) and push `main` to the remote yourself. Do not stop to ask for PR approval or wait on a separate merge step unless the user explicitly wants a PR-only workflow.
- Never open draft pull requests.
